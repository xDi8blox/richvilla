# RichVilla Apartments & Hotels: sample website

A one-page design proposal for **RichVilla Apartments & Hotels**, 28 Omu-Aran Street, Unity Estate, Egbeda, Lagos.

Live preview: https://xdiablo.xyz/richvilla/

Sample by Diablo, [xdiablo.xyz](https://xdiablo.xyz). Not RichVilla's official website.

- Plain HTML/CSS/JS, mobile-first, no build step.
- Photos: the property's own photos from its public Expedia/Hotwire listing; logo from its public Facebook page. Colour saturation was softened slightly; nothing was added or removed.
- Text: RichVilla's own page description and Facebook posts, plus amenities, apartment types and check-in/out times from its public listings.
- Prices are shown as "Rates on request". No reviews, ratings or awards are shown.
- The booking bar opens WhatsApp with the chosen dates filled in; nothing is stored.
